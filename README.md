## Deskripsi Projek

**SEN Kanan** merupakan rancangan basis data untuk sistem penjualan barang otomotif motor. Sistem ini digunakan untuk mengelola data motor milik pengguna, data pengguna dan keranjang, transaksi pemesanan, detail pesanan, katalog produk, serta mutasi stok produk.

ERD (Entity Relationship Diagram) pada projek ini menggambarkan hubungan antar tabel sehingga data dapat disimpan secara terstruktur dan mengurangi terjadinya duplikasi data.

> **Status:** tahap perancangan 

---

## Latar Belakang

- Pembeli sulit memastikan suku cadang cocok dengan tipe motornya, sehingga sering salah beli.
- Stok dan transaksi yang dicatat manual membuat data tidak akurat.
- Pencarian produk belum terstruktur berdasarkan merek, tipe, dan kategori.

## Fitur

**Pelanggan**
- Registrasi dan login
- Menyimpan data motor (merek, model, tahun, plat nomor)
- Mencari dan memfilter produk
- Keranjang dan checkout
- Melacak status pesanan

**Admin**
- Kelola produk, merek, dan stok (riwayat mutasi stok)
- Kelola pesanan
- Laporan penjualan
